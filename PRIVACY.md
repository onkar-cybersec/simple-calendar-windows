# Privacy Policy for Dayframe Calendar

Effective date: August 21, 2026

Dayframe Calendar does not collect, store, transmit, sell, or share personal information.

The application works offline and does not require an account. It contains no analytics, advertising, telemetry, or background network service. Calendar dates, holiday information, appearance settings, and live-tile content are processed locally on the user's Windows device.

The About dialog includes a link to the developer's public GitHub profile. That link opens only when the user selects it and is then governed by GitHub's privacy practices.

For privacy questions or support, open an issue at:

https://github.com/onkar-cybersec/simple-calendar-windows/issues
